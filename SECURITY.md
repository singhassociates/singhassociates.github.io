# Security Policy

## Reporting a vulnerability

If you find a security issue on the Singh & Singh Associates website, please report it privately using [GitHub vulnerability reporting](https://github.com/singhassociates/singhassociates.github.io/security/advisories/new). Include the affected page, a description of the issue, and enough information to reproduce it safely.

Please keep API keys, passwords, and client information out of public issues and screenshots.
